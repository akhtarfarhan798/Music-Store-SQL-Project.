# Music Store SQL Data Analysis Project

## Project Overview
This project focuses on analyzing a Music Store database using PostgreSQL. The objective is to explore music sales, customer purchasing behavior, popular music genres, artist performance, and revenue using SQL queries.

## Tools & Technologies
- PostgreSQL
- pgAdmin 4
- SQL

## Database Tables
The project uses the following tables:

- Artist
- Album
- Track
- Genre
- Customer
- Invoice
- Invoice Line
- Employee
- Media Type
- Playlist
- Playlist Track

## SQL Concepts Used
- SELECT, WHERE, ORDER BY, LIMIT
- INNER JOIN
- GROUP BY
- Aggregate Functions: SUM(), COUNT(), AVG()
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions: ROW_NUMBER(), RANK()
- PARTITION BY
- DISTINCT
- String Filtering using LIKE and ILIKE

## Business Questions & Analysis

### Q1. Senior Most Employee
Find the senior-most employee based on job title.

### Q2. Countries with the Most Invoices
Identify countries with the highest number of invoices.

### Q3. Top 3 Invoice Values
Find the three highest invoice totals.

### Q4. City with the Highest Revenue
Identify the city generating the highest total invoice revenue.

### Q5. Best Customer
Find the customer who has spent the most money.

### Q6. Rock Music Listeners
Identify customers who listen to Rock music and filter email addresses starting with A.

### Q7. Top 10 Rock Artists
Find the top 10 artists with the highest number of Rock tracks.

### Q8. Tracks Longer Than Average
Find all tracks whose duration is greater than the average track length.

### Q9. Customer Spending on Artists
Calculate how much each customer has spent on each artist.

### Q10. Top Spending Customer in Each Country
Identify the highest-spending customer in each country, including customers who share the highest spending amount.
